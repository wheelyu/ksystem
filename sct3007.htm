ATURAN PEMBUATAN BAHASA 3007


1. Penulisan Kode Xml 3007 selalu diawali dengan "t."


2. Penulisan "t." dalam program biasanya dipakai di dalam :

SCREEN baris paling atas

SCR_NXT_MSG

HOOKS

IMAGE


3. Pembuatan Bahasa 3007 dibuat dengan kode yang difahami dan lugas


4. Pembuatan Bahasa 3007 tidak boleh pakai spasi.


5. Jika terdiri dari dua kata atau lebih bisa disingkat dengan memakai huruf Capital didepannya

baik penulisan Kode Xml maupun penulisan dalam bahasa Indonesia

Contoh :

Kode Xml : t.TglHrsLbhBsrDrHrIni

Indonesia : Tanggal Harus Lebih Besar Dari Hari Ini

Kode Xml : t.TekanVyDuluUtkMintaApr

Indonesia : Tekan VY Dulu Untuk Minta Aproval

Kode Xml : t.NoBuk

Indonesia : NomorBukti


Kode Xml : t.TglJtpBr

Indonesia : Tgl Jtp Baru


6. Setiap kali programmer melakukan push layar ke git pastikan bahasa sudah dibuat di 3007

supaya ketika program live sudah rapi dan tidak ada lagi simbol t.??

(Bahasa 3007 dibuat dulu, baru kemudian push layar ke git)


7. Jika Bahasa 3007 sudah ada, pakailah bahasa yang sudah ada jangan membuat baru lagi.

Contoh :

Kode Xml : t.TglFakur (dibuat pada tanggal 20-09-2018)

Indonesia : TglFaktur

Kode Xml : t.TglFak (dibuat pada tanggal 19-02-2019)

Indonesia : Tgl Faktur

Dari contoh diatas t.TglFak tidak perlu dibuat lagi karena sudah ada t.TglFaktur
